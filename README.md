# guicheffer.me

Personal website - pure HTML & CSS.

🌐 **[https://guicheffer.me](https://guicheffer.me)**

## How to run

Install dependencies:
```sh
yarn install
```

Run local server:
```sh
make start
```

Or using yarn:
```sh
yarn dev
```

## Deploy

Deployed automatically via GitHub Pages pipeline.
